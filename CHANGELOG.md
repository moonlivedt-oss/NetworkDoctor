# История изменений

Формат: версия — дата, сгруппировано по разделам «Добавлено / Изменено / Исправлено».

## Не выпущено

### Изменено
- Батники больше не привязаны к Python 3.14 автора: общий `_python.cmd` ищет Python 3.10+
  (сначала тот, где уже есть PyQt6), при первом запуске сам ставит PyQt6 и запускает
  настоящий `pythonw.exe`. `Собрать exe.bat` использует тот же Python и сообщает об ошибке
  сборки, а не пишет «Готово».
- CI на тег `v*` собирает `NetworkDoctor.exe` и прикладывает его к релизу с SHA256.

### Исправлено
- Проверка обновлений смотрела в старое имя репозитория (`MoonMinder`) и работала только
  благодаря редиректу GitHub; теперь - `moonlivedt-oss/NetworkDoctor`.

## 2.6 — 2026-09-03

### Добавлено
- Рекомендация после диагностики: приложение подсказывает ОДНО лучшее действие и запускает его одной кнопкой.
- Инструмент «Тест DNS-серверов»: замеряет задержку публичных резолверов (Cloudflare, Google, Quad9, OpenDNS, Яндекс) и подсказывает самый быстрый.
- Тихая авто-проверка обновлений при запуске (раз в сутки, сообщает только если версия доступна) — включается в настройках.
- «Откат файрвола»: восстановление правил брандмауэра из ранее созданного бэкапа.
- Окно «О программе»: версия, права, ссылка на репозиторий, папка логов.
- Кнопки «Копировать» в окнах соединений, деталей адаптера и DNS.
- Горячие клавиши: F5 — проверить сеть, Ctrl+R — починить умно, Ctrl+U — обновления, F1 — о программе.
- Приложение запоминает размер и положение окна между запусками.

### Изменено
- Диагностика прокси теперь видит и прокси уровня системы (HKLM), а не только пользователя (групповая политика / стороннее ПО).
- Текстовый отчёт включает версию NetworkDoctor и сведения о системе.

## 2.5 — 2026-08-29

### Добавлено
- Живое переключение тем и акцентных цветов — оформление меняется сразу, без перезапуска приложения.
- Адаптивная вёрстка: окно и содержимое подстраиваются под размер, контент центрируется с ограничением ширины для удобного чтения.

### Изменено
- Переработано главное окно: обновлённая структура, акцентные заголовки разделов и круглые кнопки оформления.
- Внутренняя реорганизация кода по подпакетам `net/` (сетевая логика) и `ui/` (представление) — на поведение для пользователя не влияет.

# Политика безопасности

## Как сообщить об уязвимости

Пожалуйста, **не открывайте публичный issue** для проблем безопасности. Вместо этого:

- приватный канал GitHub - вкладка **Security -> Report a vulnerability** в этом репозитории;
- либо напишите автору через профиль [@moonlivedt-oss](https://github.com/moonlivedt-oss).

Опишите, что нашли, как воспроизвести и в чём потенциальный вред.

## Модель угроз

Сетевой доктор выполняет системные команды (`netsh`, PowerShell, `ipconfig`) и правит реестр,
иногда с правами администратора. Поэтому особенно важны:

- подстановка команды через ввод пользователя, имя адаптера или `config.json`;
- запуск подменённого исполняемого файла (утилиты вызываются по полному пути из `System32`);
- разрушительные действия без бэкапа или без подтверждения;
- запрос в сеть на адрес, который подсунул подменённый конфиг.

Как это уже защищено - раздел [«Безопасность» в README](README.md#безопасность). Сеть программа
использует только для проверок связи, внешнего IP, замера скорости и проверки обновлений на
GitHub; отчёты и история хранятся локально в `logs/`.
